# Contributing

Thanks for helping improve release-note-weaver-skill.

## Development

```bash
npm install
npm run release:check
```

Keep changes local-first and evidence-backed. Do not add release, publishing, tagging, or GitHub write behavior without a separate review.

## Pull Requests

- Keep fixtures small and deterministic.
- Update README examples when CLI behavior changes.
- Run `npm run release:check` before opening a PR.
